# Cloud-Based Student Assignment Submission & Feedback Portal

A full-stack cloud-ready academic platform for managing student assignments, submissions, grading, and feedback using React and FastAPI.

## Project Overview

This project provides a centralized platform where teachers can create assignments, students can submit their work, and teachers can review, grade, and provide feedback.

It includes:
- Student and teacher registration/login
- JWT-based authentication
- Role-Based Access Control (RBAC)
- Assignment creation, updating, and deletion
- Assignment submission and resubmission
- File upload and download
- Submission status tracking
- Teacher grading and feedback
- Student dashboard
- Teacher dashboard
- REST API
- SQLite database
- Local file storage
- Cloud-ready architecture
